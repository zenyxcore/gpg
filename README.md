# GPG Arquitetura

Site institucional responsivo em HTML, CSS e JavaScript. Publicação pela Vercel, sem dependências de build.

## Edição
- Textos e seções: index.html
- Identidade e responsividade: style.css
- Portfólio, filtros e visualização: app.js
- Fotos e logo: assets/

As imagens e informações iniciais foram reaproveitadas do site oficial da GPG. Novas fotografias podem substituir os arquivos em assets. Projetos podem ser adicionados à lista projects em app.js.
